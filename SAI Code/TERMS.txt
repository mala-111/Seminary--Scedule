תנאי שימוש — SAI Code
=====================

ברוכים הבאים ל-SAI Code. התקנת התוכנה והשימוש בה כפופים לתנאים הבאים.
אנא קראו אותם בעיון. לחיצה על "אני מסכים" מהווה הסכמה מלאה לתנאים.


1. מהות השירות
--------------
SAI Code מפנה את כלי התכנות Claude Code אל שרתי הסינון של SAI. כל בקשה
ותגובה עוברות סינון תוכן אוטומטי לפני שהן מוצגות. התוכנה מיועדת לשימוש
בפעולות תכנות ופיתוח תוכנה בלבד.


2. דרישת מנוי
-------------
השימוש ב-SAI Code מותנה בחשבון SAI פעיל הכולל הרשאת SAI Code. צריכת
השירות נמדדת ומחויבת מתוך יתרת החשבון, בהתאם למסלול שנרכש. ניתוק או
ביטול המנוי מפסיק את הגישה לשירות.


3. שימוש מותר
-------------
התוכנה מיועדת לתכנות בלבד. חל איסור על שימוש לצרכים שאינם תכנותיים,
לרבות ניסיון לעקוף את מנגנון הסינון, להפיק תוכן אסור, או לפתח פרויקטים
המנוגדים למדיניות התוכן של SAI. SAI רשאית לחסום גישה במקרה של שימוש
לרעה.


4. פרטיות ונתונים
-----------------
לצורך הסינון והחיוב, בקשות עוברות דרך שרתי SAI ועשויות להיות מעובדות
ומתועדות בהתאם למדיניות הפרטיות של SAI. אין להזין בתוכנה מידע רגיש
שאינו נדרש למשימת התכנות.


5. אחריות
---------
התוכנה ניתנת "כפי שהיא" (AS IS), ללא אחריות מכל סוג. SAI אינה אחראית
לנזק ישיר או עקיף הנובע מהשימוש בתוכנה, לרבות אובדן נתונים או שגיאות
בקוד שנוצר. האחריות לבדיקת הקוד והתאמתו חלה על המשתמש.


6. רכיבי צד שלישי
-----------------
ההתקנה כוללת או מתקינה רכיבים של צד שלישי (Node.js ו-Claude Code).
השימוש בהם כפוף לרישיונות שלהם. SAI אינה הבעלים של רכיבים אלה.


7. שינויים
----------
SAI רשאית לעדכן תנאים אלה ואת השירות מעת לעת. המשך השימוש לאחר עדכון
מהווה הסכמה לתנאים המעודכנים.
